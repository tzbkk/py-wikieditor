# restore_from_history.py - 历史版本恢复工具

## 功能

当转换出现问题时，可以从历史版本恢复页面到最近一次非 bot 转换的版本。

## 用法

```bash
python src/restore_from_history.py <page_name>
python src/restore_from_history.py <page_name> --show-versions
```

### 参数

- `page_name`: 要恢复的页面名称
- `--show-versions`: 只显示历史版本，不恢复

## 示例

```bash
# 恢复单个页面
python src/restore_from_history.py "西片"

# 查看页面的历史版本
python src/restore_from_history.py "西片" --show-versions

# 通过 fandom.py 等价调用
python src/fandom.py restore "西片"
python src/fandom.py restore "西片" --show-versions
```

## 工作流程

恢复模式：

1. 获取页面的最近 50 个历史版本
2. 跳过 bot 转换相关的版本（通过编辑摘要关键词识别）
3. 找到最近一次非 bot 编辑的版本
4. 恢复该版本的内容到页面

显示版本模式：

1. 获取页面的最近 50 个历史版本
2. 列出每个版本的 ID、时间、编辑者和摘要
3. 不进行任何修改

## 特性

- 自动跳过 bot 转换相关的版本
- 通过编辑摘要关键词识别 bot 编辑
- 支持查看历史版本列表
- 恢复前显示版本信息
- 只恢复内容，不修改编辑历史

## 使用场景

- 转换出现错误需要回退
- 需要查看页面的编辑历史
- 需要恢复到特定版本
- 批量转换出现问题时的补救

## 注意事项

- 恢复操作会覆盖当前页面内容
- 恢复后原内容将丢失
- 建议先用 --show-versions 查看版本历史
- 确认目标版本后再恢复
- 恢复操作会创建新的编辑记录
- **脚本只修改 Wiki 页面内容，不会修改任何脚本文件**

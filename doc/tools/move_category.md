# move_category.py - category 页面移动工具

## 功能

移动 category 页面到简体中文名称。按照规矩先更新所有引用该 category 的页面，然后再移动 category 页面本身。

## 用法

```bash
python src/move_category.py <old_name> <new_name>
python src/move_category.py --from-file categories.txt
python src/move_category.py "旧分類" "新分類" --dry-run
```

### 参数

- `old_name`: 旧分类名称（不含 Category: 前缀）
- `new_name`: 新分类名称（不含 Category: 前缀）
- `--from-file FILE`: 从文件读取分类列表
- `--dry-run`: 预览模式

## 示例

```bash
# 移动单个分类
python src/move_category.py "舊分類" "新分類"

# 预览移动
python src/move_category.py "舊分類" "新分類" --dry-run

# 从文件批量移动
python src/move_category.py --from-file categories.txt

# 通过 fandom.py 等价调用
python src/fandom.py move-category "舊分類" "新分類"
python src/fandom.py move-category "舊分類" "新分類" --dry-run
```

## 工作流程

对于每个分类：

1. 检查目标分类是否已存在
2. 步骤 1/2：更新引用
   - 获取所有成员页面
   - 获取所有包含该分类链接的页面
   - 更新这些页面中的分类引用
   - 显示更新统计
3. 步骤 2/2：移动页面
   - 移动 category 页面到新名称
   - 不创建重定向
4. 显示总体统计

## 特性

- 先更新所有引用，再移动页面（避免链接断裂）
- 支持批量移动多个分类
- 从命令行参数或文件读取分类列表
- 自动生成新名称（如果未提供）
- 预览模式查看将要执行的操作
- 支持各种格式的分类链接
- 统计信息显示成功/失败/跳过数量
- 不创建重定向

## 使用场景

- 批量重命名分类页面
- 繁体分类名转简体
- 统一分类命名规范
- 整理分类结构

## 注意事项

- 移动后原分类名不再可用
- 可能影响引用该分类的所有页面
- 移动操作不可逆
- 建议先使用 --dry-run 预览
- 建议先在小范围测试
- 与 move_pages.py 的区别：先更新引用，再移动页面
- **脚本只移动 Wiki 页面，不会修改任何脚本文件**

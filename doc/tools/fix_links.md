# fix_links.py - 链接批量修复工具

## 功能

批量修复页面中的链接，将繁体中文链接替换为简体版本。支持多种链接格式的智能替换。

## 用法

```bash
python src/fix_links.py <old_text> <new_text>
python src/fix_links.py "舊文本" "新文本" --limit 5
python src/fix_links.py "舊文本" "新文本" --dry-run
```

### 参数

- `old_text`: 要替换的旧文本
- `new_text`: 替换后的新文本
- `--limit N`: 限制处理的页面数量
- `--dry-run`: 预览模式

## 示例

```bash
# 修复页面链接
python src/fix_links.py "擅長捉弄的(原)高木同學" "擅长捉弄的(原)高木同学"

# 限制处理数量
python src/fix_links.py "舊文本" "新文本" --limit 5

# 预览模式
python src/fix_links.py "舊文本" "新文本" --dry-run

# 通过 fandom.py 等价调用
python src/fandom.py fix-links "舊文本" "新文本"
python src/fandom.py fix-links "舊文本" "新文本" --limit 5 --dry-run
```

## 工作流程

1. 搜索包含旧文本的页面
2. 对于每个页面：
   - 获取页面内容
   - 智能替换各种格式的链接
   - 如果有修改，保存更改
3. 显示统计信息

## 智能替换规则

工具会自动替换以下格式的链接：
- `[[页面名]]` → `[[新页面名]]`
- `[[页面名|显示文字]]` → `[[新页面名|显示文字]]`
- `[[ 链接]]`（带空格）→ `[[ 新链接]]`
- `|链接]]` 格式（链接作为参数）→ `|新链接]]`
- `Category:页面名` → `Category:新页面名`
- `Template:页面名` → `Template:新页面名`
- `模板:页面名` → `模板:新页面名`
- `File:页面名` → `File:新页面名`
- `文件:页面名` → `文件:新页面名`

## 特性

- 智能识别多种链接格式
- 支持内部链接、分类链接、模板链接、文件链接
- 支持中文和英文命名空间
- 搜索包含旧文本的所有页面
- 预览模式查看将要执行的修改
- 统计信息显示成功/失败/跳过数量
- 自动排除页面本身（避免循环）

## 使用场景

- 页面重命名后批量更新链接
- 繁体链接转简体
- 批量修正错误链接
- 统一链接命名规范
- 更新分类引用

## 注意事项

- `old_text` / `new_text` 要尽量精确，避免误替换
- 建议先使用 --dry-run 预览
- 建议先在小范围测试
- 替换操作不可逆
- 确保新页面名存在
- 建议先移动页面再修复链接
- **脚本只修改 Wiki 页面内容，不会修改任何脚本文件**

# scan_redlinks.py - 红链扫描工具

## 功能

扫描全 Wiki 的红链(指向不存在页面的链接),读取本地 dump 数据中的 wikitext,提取所有 `[[链接]]` 并检查目标页面是否存在,生成分类报告。

## 用法

```bash
python src/scan_redlinks.py
python src/scan_redlinks.py -o report.txt
```

### 参数

- `-o, --output` <str> — 输出到文件(默认打印到终端)
- `--dump-dir` <str> — dump 目录路径(默认 `wiki_dump/`)

## 示例

```bash
# 基础扫描(打印到终端)
python src/scan_redlinks.py

# 输出报告到文件
python src/scan_redlinks.py -o redlinks.txt

# 指定自定义 dump 目录
python src/scan_redlinks.py --dump-dir my_dump

# 扫描并保存报告
python src/scan_redlinks.py -o reports/redlinks_2024_01.txt

# 快速查看红链数量
python src/scan_redlinks.py | grep "全 Wiki 红链报告"
```

## 工作流程

1. 读取 `wiki_dump/index.json` 获取所有已存在页面
2. 遍历每个 `.wiki` 文件,提取 wikitext 内容
3. 使用正则匹配所有 `[[链接]]` 形式的内部链接
4. 检查链接目标是否在索引中存在
5. 过滤噪声页面和特殊命名空间链接
6. 按类别分组输出红链报告

## 特性

- 自动跳过噪声页面(/doc、/test、/sandbox 等)
- 过滤特殊命名空间链接(file:、category:、template: 等)
- 按类别分组显示红链(漫画卷、章节、人物等)
- 显示每个红链被引用的次数和来源页面
- 支持输出到文件或终端
- 快速扫描,无需网络请求

## 使用场景

- 清理 Wiki 前发现孤立链接
- 批量创建缺失页面前的盘点
- 检查 Wiki 内容完整性
- 识别需要创建的页面优先级
- 定期维护 Wiki 链接质量
- 数据迁移前的健康检查

## 依赖

此脚本必须依赖 `dump_wiki.py` 产生的数据:

```bash
# 先运行 dump_wiki.py 准备数据
python src/dump_wiki.py

# 再运行 scan_redlinks.py 扫描红链
python src/scan_redlinks.py
```

必须确保 `wiki_dump/index.json` 和所有 `.wiki` 文件完整存在。

## 注意事项

- 必须先运行 `dump_wiki.py` 准备数据
- Module 命名空间(828)中的 `[[...]]` 是代码引用,会被自动跳过
- 跨语言链接(en:、vi:、ko: 等)会被自动过滤
- 外部链接和非主空间链接不会被视为红链
- 噪声页面(/doc、/preload、/test 等)会被自动跳过
- 红链按引用次数降序排列,优先处理高频红链
- 报告按类别分组便于批量处理
- **脚本是只读操作,不会修改任何 Wiki 页面**
